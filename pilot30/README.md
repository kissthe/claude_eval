# 30题 Pilot v1.0（待人工复核）

本目录使用项目原始 `locomo10.json` 的6个指定锚点构造30道新英文输入，H/P/I各10题，I的两个子类各5题。旧版题目、旧自评成绩未使用。

## 文件

- `protocol_v1.md`：用户提供的原始方案副本。
- `pilot_questions.json`：模型可见题目，无答案、锚点编号、题型或标注理由。
- `pilot_answers.json`：运行前冻结的候选参考答案与可接受最小证据集合。
- `review_sheet.json`：锚点、逐题理由、历史证据、负例检索记录，以及待填写的两位人工审核者字段。
- `data_manifest.json`：数据版本、分布、源文件和题目/答案哈希。

候选参考答案由当前代理整理并核对原始证据，**没有冒充双人独立人工标注**。人工一致率、kappa、裁决数均不可用。数据冻结后未根据被测模型输出修改题目或参考答案。

## 已完成运行

结果目录：`results/pilot30_gpt6_luna_20261008/`。

- `report.md`：中文报告，含分类、证据、误归因、资源、区间和典型错误。
- `scores.json`：机器可读指标。
- `per_item_results.csv` / `.json`：90次请求的逐题对照。
- `blind_error_review.json`：隐藏模型名称的错误复核包，供研究者独立编码。
- `requests/`：实际发送的全部输入（不含API密钥）。
- `raw/`：全部原始响应、解析结果、用量和耗时。
- `config.json` / `request_index.json`：冻结参数、输入哈希与历史轮次数。

指定的`gpt6-luna`被AiHubMix拒绝；实际接口ID为`gpt-6-luna`，返回快照为`gpt-6-luna-2026-09-22`。90次测试全部收到响应，5次因256 token预算被内部推理耗尽而返回空内容，严格计错，未补问。

## 复算与后续复核

运行 `python tools/score_pilot30.py` 可从保存的结果复算全部指标，无需联网或密钥。调用程序从进程环境变量`AIHUBMIX_API_KEY`读取密钥，代码、请求和报告不保存密钥。

本次输入和结果已经冻结；不要在原结果目录重新执行`prepare`、`probe`或改写Gold。若人工复核发现真实题目/证据问题，或需要增加推理预算/更换模型，请另建版本和运行目录，记录修订并重跑所有条件。`run`会跳过已经保存的结果，包括无效输出。

正式评测仍需完成方案要求的两位审核者独立两遍审核与第三人裁决，以及用户选择的开源对照模型。报告仅对这批受控合成诊断题提供初步结论。
